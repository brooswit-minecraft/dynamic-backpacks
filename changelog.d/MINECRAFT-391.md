### Added
- Emerald wallet: always-on consolidation of loose emeralds and emerald blocks across the main inventory, including the hotbar, into a stable 56-64 loose reserve, independent of any backpack. Surplus above 64 packs into blocks and a shortfall below 56 unpacks blocks, at the vanilla 9:1 ratio, with exact value conservation and no change when the reserve is already stable. A conversion that cannot fit in the inventory is deferred rather than ever dropping or duplicating items, and a stack carrying a custom name or other data component is left untouched rather than merged/split. An already-stable layout is never shuffled: once the loose/block totals already match the target, nothing is rearranged, even to merge same-kind stacks sitting in separate slots; otherwise each required stack prefers a slot already holding that kind, so the player's selected hotbar slot keeps the loose reserve only when it already holds loose emeralds, never displacing a block (or anything else) sitting there.
